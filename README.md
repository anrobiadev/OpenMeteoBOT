# OpenMeteoBOT
Bot personal de vreme bazat pe Open-Meteo (gratuit, fără cheie API), care rulează pe Raspberry Pi / Linux. Oferă prognoză orară și pe mai multe zile, umiditatea solului, date istorice și alerte automate (vânt, ploaie, ninsoare, caniculă, îngheț) pentru locații salvate. Funcționează pe Telegram și, opțional, pe WhatsApp.
